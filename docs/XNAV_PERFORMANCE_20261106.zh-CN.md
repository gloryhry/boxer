## 实施与排错

- `xnav_prepare_workers=1|2`，CLI/HTTP/Web 默认 `2`。相机反投影按 65,536 点分块；相机及 OWL 预处理复用两个线程，内部相机任务直接计算，避免嵌套等待。
- 自动 CUDA 流水线预取锁页内存，按视图异步上传并用 events 管理依赖；原生图像的 GPU 输入供 DINO/Boxer 共用。固定相机射线缓存、CPU 相机类型和尺寸元数据减少重复工作，按帧继续应用位姿。
- 合并 OWL 回传等待，延后 DINO 描述符回传；在输出发布之前完成 CPU 数组。Boxer 可选择不复制中间特征；原模型调用默认行为保持兼容。
- 并发准备的早期版本出现过点云差异。最小测试在本机 OpenBLAS 0.3.29 的并发窄矩阵乘法中复现坐标数据损坏；仅对坐标矩阵乘法加锁后，500 次矩阵压力测试、30 轮真实准备重复测试和整张 img2 的 938 个观测哈希均通过。未放宽结果容差，未修改精度，也未采用没有解决问题的 cuBLAS 工作区设置。
- 额外检查了复用 DINO 归一化常量及 CUDA Graph。隔离实验中完整 patch/CLS 特征逐值一致，单图像 p50 改善约 1% / 2%，未验证整图收益，因此未纳入默认路径。

本轮 `img7` 的 10% 整图目标尚未达成。32 帧阶段样本中，跟踪 p50 为 1.21 秒，模型阶段的改善并未同比反映到整图耗时；该瓶颈仍需进一步优化。
