# Tests

## Setup

```bash
pip install pytest pytest-cov scipy
```

`scipy` is only needed as a reference for validating our pure-Python replacements (Hungarian algorithm, connected components).

The optional viewer compatibility tests use the installed `imgui-bundle` binding
without a display or GPU. They can also run without pytest:

```bash
python -m unittest discover -s tests -p test_imgui_compat.py -v
```

## Running Tests

From the repo root:

```bash
# Run all tests with coverage report
tests/run_tests.sh

# Run without auto-opening the HTML report
tests/run_tests.sh --no-open

# Run a specific test file
python -m pytest tests/test_fusion.py -v
```

## Coverage

After running `tests/run_tests.sh`, the HTML coverage report is at `tests/htmlcov/index.html`.

On the deployed Jetson, include the bundled encoder and CUDA libraries when
running the output-failure and CUDA geometry tests:

```bash
export PATH="$PWD/.runtime/bin:$PATH"
export LD_LIBRARY_PATH="$PWD/.runtime/lib${LD_LIBRARY_PATH:+:$LD_LIBRARY_PATH}"
OMP_NUM_THREADS=4 MKL_NUM_THREADS=4 .venv/bin/python -m pytest -q \
  tests/test_xnav*.py tests/test_owl_batch.py tests/test_track_3d_boxes.py \
  tests/test_fusion.py tests/test_file_io.py tests/test_gravity.py \
  tests/test_imgui_compat.py tests/test_camera.py tests/test_boxernet.py \
  tests/test_boxernet_utils.py
```

The x-nav camera golden vectors in `fixtures/xnav_camera_reference.csv` were
generated by `reference_xnav_cameras.cpp` linked against the actual x-nav vikit
camera sources. `fixtures/xnav_camera_reference_sources.json` records their
SHA256 hashes. The standalone reference executable only needs Eigen, OpenCV,
and the vikit headers/sources; `math_utils.h` includes an unused Sophus alias.
When Sophus is absent, an isolated include directory containing
`namespace Sophus { class SE3d; }` in `sophus/se3.hpp` is sufficient for this
reference executable. No x-nav camera source is edited. Filter constructor
diagnostics from stdout when regenerating the fixture (keep nine-column rows).
